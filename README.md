# Unity 智能家庭语音 Agent

一个以 Unity 虚拟全屋为交互载体的语音 Agent 项目。理解自然语言意图，结合人物模拟位置和设备状态执行家居控制、跨房间通知，并展示结果。

> 当前阶段：设计已批准，尚未实现可运行应用。仓库当前只有设计与项目说明，不包含模型权重或 API 密钥。

## 第一版范围

- 简化 3D 厨房、客厅、卧室；圆点与名字显示人物，手动移动模拟位置。
- 虚拟灯、空调、模拟室温及房间播报点。
- 本地唤醒后连续对话；20 秒无新语音退出，播报期间暂停识别。
- SenseVoiceSmall ONNX 本地 ASR、Kokoro/sherpa-onnx 本地 TTS。
- 本地人物检测＋手动身份绑定，不自动推断说话者或全屋位置。
- 云端文本大模型负责意图理解与工具选择，本地服务检查并执行。
- Unity 显示状态变化；使用单个电脑扬声器模拟不同房间播报，不代表物理分区播放。

## 数据与仓库边界

原始音视频默认不持久保存；云端只接收任务必要的文字和场景信息。密钥只保存在本地服务配置，不进入 Unity 包或 Git。

当前工作区同时存在无关文件，因此 `.gitignore` 暂采用根目录允许列表，只开放项目说明和设计/计划目录。后续新增应用目录时需显式加入允许列表；不要使用强制添加把依赖、模型、日志或个人文件上传。

本仓库尚未指定项目代码许可证；第三方软件、模型权重和素材须分别核验使用条件。
